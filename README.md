# Partified

A static landing page concept for the Partified web + mobile experience focused on underground house music events in the DMV.

## Preview locally

```bash
python -m http.server 8000
```

Then open <http://127.0.0.1:8000> in your browser.

If you prefer another port:

```bash
python -m http.server 5173
```

Then visit <http://127.0.0.1:5173>.
